# 007 (feat): チャンネル一覧（conversations.list）の結果をしばらくキャッシュする

起票日: 2026-10-07

## 概要

大きなワークスペースでは `conversations.list` の全件取得が重い（ubiregi は約 3500 チャンネルで、1 回の取得に約 18 リクエスト。
`conversations.list` の制限は 1 分あたり 20 回前後で、数分のうちに 2 回取ると 429 になる。issue 006 の「現状」節の実測）。
チャンネルの一覧はそう頻繁に変わらないので、取得した結果をしばらく手元に置き、次の実行ではそれを使う。

006（429 を受けたら待って続きを取る）とは直すものが違う。006 は「1 回の取得を最後まで終わらせる」、本 issue は「取りに行く回数を減らす」。

## 使う場所

- `slack channels`（`-n` を付けない全件取得）: キャッシュが新しければそれを返す。`-name` / `-n` の絞り込みは今どおり手元で行う
- チャンネル名 → ID の解決（`ResolveChannel`。`slack history '#name'` / `slack thread '#name' …`）: キャッシュに名前があれば、その ID を
  `conversations.info` で確かめ、今の名前と一致したときだけ使う。一致しない・無い・確かめられないときは今どおり API を 1 ページずつ探す

## 仕様（2026-10-07 決定。有効期限 1 時間・users はキャッシュしない、は推奨値で決めた）

- 置き場所: 設定ディレクトリの `cache/`（`$XDG_CONFIG_HOME/slack-cli/cache/`。プロファイルのキャッシュ `profileCachePath` と同じ場所。
  ディレクトリ 0700・ファイル 0600）。`~/Library/Caches/slack-cli/` は使わない（`extract/` は Cookie の一時コピーの作業領域で、起動時の掃除が
  走る。`<workspace>/` を並べると、workspace 名が `extract` のときにぶつかる）
- キー: workspace・ユーザー ID（`auth.test` の `user_id`）・種別（`-types` を並べ替えて正規化したもの）。ファイル名にそのまま入れるので、
  それぞれ文字種を確かめ、合わなければキャッシュを使わない。`-types` の絞り込みは手元ではできない（`Channel` に種別の項目が無い）ので、種別ごとに別に持つ
- 中身: 取得時刻・キー・`Channel` のスライス（`-json` の出力と同じ構造体）。読むときにキーと形式の版が一致し、取得時刻が 1 時間以内（未来の時刻は古い扱い）の
  ときだけ使う。読めない・壊れている・合わないときは使わずに API から取る（正しさをキャッシュに預けない）
- 書くのは全件の取得が最後まで成功したときだけ（`PartialError` / `TruncatedError` / `-n` で途中で止めた取得は書かない）。一時ファイル + rename で書く
  （同時に走っても壊れたファイルを残さない）
- `-refresh`（`channels` / `history` / `thread`）でキャッシュを読まずに取り直し、成功したら書き直す
- キャッシュを使ったときは stderr に 1 行出す（何分前に取得したか、`-refresh` で取り直せること。stdout には出さない）
- 🚨 プライベートチャンネルの名前・トピックがディスクに残る。cookie / トークンは入れない。README「安全のための制約」に何を残すかを書く
- `is_member` / `num_members` / トピックは最大 1 時間古いことがある（README に書く）

- [x] `-types` が違えば別のキャッシュになる。ユーザー・workspace が違っても別になる
- [x] 1 時間を過ぎた・壊れた・形式やキーが合わないキャッシュは使わず、API から取り直す
- [x] 途中で失敗した・打ち切られた・`-n` で止めた取得はキャッシュに書かない
- [x] `-refresh` でキャッシュを読まずに取り直し、書き直す
- [x] `history '#name'` はキャッシュの ID を `conversations.info` で確かめてから使う。名前が変わっていたら API で探し直す（古い名前で別のチャンネルを読まない）
- [x] ファイルは 0600・ディレクトリは 0700。cookie / トークンが入らない
- [x] help・README を更新する
