# issues

このリポジトリの課題管理。1 課題 1 ファイルで `NNN-<種別>-<スラッグ>.md`。

- 種別: `bug` / `feat` / `chore` / `refactor` / `human`（人しかできない作業）/ `retro`（セッションの振り返り）
- 完了したら `issues/done/` へ移す（未読 = `issues/`、確認済み = `issues/done/` で状態を表す）
- `human` は動作確認・目視レビュー・外部サービスの操作など**人しかできない作業**。本文に `期限: YYYY-MM-DD` を書く
- 作業中は commit のたびに該当 issue へ進捗・結果・残タスクを追記する（chat の報告は流れる。issue が唯一残る）
